## 1. 系统是做什么的

系统分为两大部分：

| 模块 | 功能 |
|------|------|
| **热榜/龙虎榜/AI 分析** | 数据采集与复盘：顽主杯热榜 Top10、东方财富龙虎榜信号、AI 复盘报告 |
| **交易决策** 📊 | 每日生成**下一交易日的条件买卖计划**：哪些股票满足买入条件、买多少、止损在哪、持仓要不要卖 |

**重要理念**：系统不预测涨跌，只输出**条件计划**——"如果明天股价突破 X 且不高于 Y，则买入 Z 股，止损 W"。所有建议都有规则依据（评分、市场状态、风控限制），最终决策由你确认。

## 2. 每日使用流程（核心）

### 晚间（数据采集 + 计划生成，约 20:00-20:30）

如果服务器上的定时任务正常运行，以下步骤**全自动**：

```
20:00  热榜爬取          ← 前提：服务器 cron 已配置
20:10  热榜Top10 → 股票池 自动同步
20:15  更新股票池+基准行情（东方财富，失败自动切 AKShare）
20:20  T+1复核（昨日买入恢复可卖、未触发标记）
20:25  自动生成次日交易计划
23:30  数据库自动备份
```

### 你的实际操作（晚间，约 5 分钟）

1. **打开 📊 交易决策 → 次日计划**
2. 查看今晚生成的计划：
   - **条件买入**（蓝色）：列出股票、触发价、禁止追高价、建议数量、止损价、最大亏损金额
   - **持仓处理**（绿/黄/红）：持有/减仓/退出建议排在最前面
   - **观察**（灰色）：评分不错但条件未满足，先看着
3. 确认无误后点击 **发布计划**（发布后不可修改）

### 次日（盘中执行 + 录入）

1. 按计划盯盘：股价**触及触发价**且**未超追高价**才买；超了就不追
2. 成交后在 **持仓与成交** 页录入实际成交（买/卖、价格、数量、佣金）
3. 系统自动更新现金、持仓、T+1 可卖数量

### 随时

- **总览**页看账户净值、仓位、回撤、市场状态
- **回测与复盘**看策略历史胜率/期望值（Phase 5 已交付，前端面板待接入）

## 3. 交易决策各页面说明

### 3.1 总览

显示账户净值五卡片（净值/现金/持仓市值/总仓位/最大回撤）、市场状态（进攻/中性/防守 + 建议仓位）、最近计划摘要、数据健康摘要。

> 总览的数据来自净值快照。**首次使用或当日行情未更新时，卡片显示的是现金余额**，属正常现象。

### 3.2 股票池

**股池决定计划从哪些股票里选。**

| 操作 | 说明 |
|------|------|
| 从热榜同步 | 点不了？用下面的手动方式。定时任务 20:10 自动同步热榜 Top10 |
| 手动导入 | 文本（每行一个：`000636 风华高科`）或 CSV（`code,name` 表头） |
| 版本对比 | 选中版本后自动与上一版本对比，绿色=新增、红色=删除 |
| 幂等 | 成分没变不会新建版本，随便重复导入 |

### 3.3 持仓与成交

| 操作 | 说明 |
|------|------|
| 选择账户 | 页面顶部选择/创建账户 |
| 录入成交 | 买/卖、代码、日期、价格、数量（100 的整数倍）、佣金、税费 |
| 对账校正 | 输入券商 App 显示的实际持仓，系统对比差异（数量/可卖/成本），**确认后**才覆盖系统值 |
| 净值快照 | 点按钮计算当日净值（持仓必须有当日行情，否则报错提示） |

**T+1 规则**：当天买入的股票 `可卖数量 = 0`，次日 20:20 定时任务自动恢复可卖。

### 3.4 次日计划

- **生成计划**：选信号日期 + 股池版本 + 策略版本 → 生成
- **同一输入重复生成 = 同一计划**（幂等），改了股池/策略才会生成新版本（旧的标记"已替代"）
- **计划状态**：
  - `READY` 就绪 / `PARTIAL` 部分就绪（有非关键数据缺失，黄色提示）
  - `BLOCKED` 已阻断（数据不完整，**红色横幅说明原因，无法发布**——先去数据健康页修复）
  - `PUBLISHED` 已发布（不可改）
- **明细字段**：
  - 触发价：明天突破此价才买
  - 禁止追高价：开盘或成交价高于此价放弃
  - 止损价 / +2R 目标价
  - 建议数量 / 仓位占比 / 最大亏损金额

### 3.5 策略设置

策略参数**版本化管理**：修改参数 = 创建新草稿版本 → 激活 → 旧版本自动退役，历史计划不受影响。

常用参数见[第 4 节](#4-策略参数调节)。

> **激活门禁**：激活前系统会检查该策略的回测指标（≥100 笔交易、期望值>0、盈利因子>1 等）。**新策略没有回测记录时无法激活**——先跑一次回测。

### 3.6 数据健康

红黄绿三色状态：

| 状态 | 含义 | 处理 |
|------|------|------|
| 🟢 OK | 基准+股池行情齐全 | 无 |
| 🟡 PARTIAL | 少量缺失（≤5%） | 可以生成计划，注意提示 |
| 🔴 BLOCKED | 基准缺失或股池缺失>5% | **先更新数据**（见常见问题 Q2） |

## 4. 策略参数调节

路径：**交易决策 → 策略设置 → 新建草稿**（参数以当前激活版本为底稿）

| 参数 | 默认 | 调节建议 |
|------|------|---------|
| **最低候选评分** | 70 | **热榜短线股普遍 40-65 分，如果计划里总是没有"条件买入"，把它降到 55-60** |
| 策略单笔风险 | 0.5% | 每笔交易最大亏损占净值比例。激进 1%，保守 0.3% |
| 策略单笔风险上限 | 0.5% | 限制市场状态、连续亏损或数据降级调整后的单笔风险上限 |

**固定规则**：最小止损距离固定为 3%，最大止损距离固定为 10%，本期不支持在策略设置中修改。

**账户风险参数**：单只股票仓位、总仓位、同行业仓位、最大持仓数量和账户回撤暂停阈值，请在**交易决策 → 持仓与成交 → 账户管理**中修改；它们不会写入策略草稿。

**风险提示**：提高策略单笔风险或策略单笔风险上限属于高风险修改，系统会弹二次确认。

**公式说明**：本期仅修正策略设置的展示和草稿序列化，评分、仓位和止损距离计算公式均未改变。

**热榜加分机制**（自动生效，无需配置）：股票池里的股票若近 5 日上过热榜——在榜 +2 分、连续在榜每天再 +1、排名 Top5 +2 / Top3 +3、排名上升 +2，合计最多 +10 分。

## 5. 定时任务

服务器上需要两组定时：

| 时间 | 任务 | 依赖 |
|------|------|------|
| 20:00 | 热榜爬虫（`python crawl.py`） | 系统 cron（`setup_crawler_cron.sh`）|
| 20:10-23:30 | 股池同步→行情→复核→计划→备份 | scheduler 进程（`python -m backend.trading.jobs.scheduler`） |

**scheduler 启动方式**（二选一）：
```bash
# 方式1: docker-compose（推荐,已配置好）
docker-compose up -d scheduler

# 方式2: 直接跑
python -m backend.trading.jobs.scheduler
```

## 6. 常见问题排查

### Q1: 计划里全是"观察"，没有"条件买入"

**最常见原因**：评分不够 70 分门槛。
- ✅ 解法 1：策略设置里把"最低候选评分"降到 55-60
- ✅ 解法 2：确认股票池是热榜同步的（热榜股有加分）
- 查看每只股票的"未命中条件"列可看到具体原因（如 `SCORE_BELOW_70`）

### Q2: 数据健康显示 BLOCKED / 计划被阻断

行情数据没更新。手动触发：
```bash
# 服务器上执行,或等 20:15 定时任务
curl -X POST "http://localhost:8888/api/trading/data-jobs" \
  -H "Content-Type: application/json" \
  -d '{"job_type": "update_bars"}'
```
然后刷新数据健康页（任务几秒内完成）。

**注意**：非交易日/收盘前基准指数没有当日数据，属于正常 BLOCKED，次日开盘后恢复。

### Q3: 总览页数据空白

- 没创建账户 → 去"持仓与成交"创建
- 无持仓时净值=现金，市值=0，正常
- 若仍异常，检查 `/api/health` 是否 ok

### Q4: 热榜数据不更新

线上检查热榜最后日期：
```bash
curl http://localhost:8888/api/dates | head -c 100
```
如果最后日期不是最近交易日 → 热榜 cron 停了：
```bash
python crawl.py          # 手动补当天
```
> ⚠️ 2026-08-14 检查发现线上热榜停在 08-06，请确认服务器 cron 状态。

### Q5: 激活策略失败

新策略必须先有回测记录：
1. 用该策略跑一次回测（`POST /api/trading/backtests`）
2. 回测达标（≥100 笔、期望值>0、盈利因子>1）才能激活

### Q6: 卖出提示"可卖数量不足"

T+1 限制：当日买入当日不可卖。次日 20:20 定时任务自动恢复；急用可重启后调 `roll_t1_available`。

### Q7: 手动同步热榜到股池

```bash
curl -X POST "http://localhost:8888/api/trading/stock-pools/sync-from-hotlist"
```
成分与上次相同时幂等（不新建版本）。

## 7. 其他功能（热榜/龙虎榜/AI）

### 热榜日报
- 每日 Top10 卡片、连续上榜/黑马追踪、近 5 日对比、趋势图
- 顶部"拉取数据"按钮手动触发当日爬取

### 龙虎榜
- 信号股：**境外机构**（国泰海通总部等 5 席位）和**机构密集**（10 席位中 ≥6 个机构专用）
- 股池追踪：信号股自动入池，跟踪 D1-D30 涨跌幅
- 胜率回测：按月/板块统计信号有效性

### AI 分析 🤖
- 每日复盘 / 智能选股 / 信号诊断（离线生成后导入，前端只读）
- 导出数据给 LLM 分析：`python export_ai_data.py [日期]`
