# 需求文档 (PRD)

## 优先级说明

- **P0 高频实用** — 核心价值功能，强烈推荐优先实现
- **P1 中频增值** — 增值功能，值得做
- **P2 锦上添花** — 低频但有趣，有精力再做

---

## P0 - 高频实用

### 1. 热榜连板统计 / 热度趋势分析

**目标**：识别持续性热点 vs 一日游

**功能点**：
- 连续多日上榜的股票，展示上榜天数、热度变化趋势（上升/下降/稳定）
- "黑马追踪"：从排名 5-10 飙升到 Top3 的股票
- 支持按连板天数排序

**技术方案**：
- 后端：对 `stock_records` 按日期范围查询，在应用层按 `stock_code` 聚合，计算连续上榜天数和排名变化
- 新增 API：`GET /api/stats/streak?days=30` — 返回近 N 天的连板统计
- 前端：新增连板统计卡片/表格组件，嵌入 DailyView

**数据基础**：`stock_records` 表已有完整数据，无需新增采集

---

### 2. 个股详情页

**目标**：从"看热闹"变成"看门道"

**功能点**：
- 点击任意股票名，展示该股历史热榜排名曲线、每次上榜时的涨跌幅
- 关联龙虎榜数据（如果该股同日有龙虎榜记录，展示买卖明细）
- 展示概念板块标签

**技术方案**：
- 后端：新增 API `GET /api/stocks/{code}/history` — 查询指定股票所有上榜记录（含龙虎榜关联）
- 前端：新增 `StockDetailView` 视图或弹窗，含排名趋势折线图 + 龙虎榜明细表格
- 路由：`/stock/:code`（弹窗形式则不需要新路由）

**数据基础**：`stock_records` + `lhb_signals` + `lhb_trading_desk` 已有关联字段 `stock_code`

---

### 3. 每日复盘报告（自动生成）

**目标**：省去每天手动看盘的功夫

**功能点**：
- 每天 20:00 爬完数据后，自动生成文字分析报告：
  - 今日 Top3 vs 昨日变化（新进/退出/排名变动）
  - 连板股名单和持续天数（依赖需求1）
  - 龙虎榜信号股汇总
  - 板块热度分布变化
- 页面展示复盘报告列表，支持按日期查看
- **推送功能后续再加，当前先做页面展示**

**技术方案**：
- 后端：新增 `GET /api/reports/daily?date=` — 基于已有数据实时计算生成报告
- 可选：将报告缓存到新表 `daily_reports`，避免重复计算
- 前端：DailyView 中新增复盘报告 tab 或折叠面板

**数据基础**：`stock_records` + `lhb_signals` 已有，连板统计依赖需求1

---

### 4. 信号股胜率回测

**目标**：验证信号有效性，调整策略

**功能点**：
- 统计境外机构信号的胜率（d1-d30 各周期）、机构密集信号的胜率
- 按月拆分胜率趋势
- 按板块拆分胜率
- 展示平均涨幅、中位数涨幅、最大回撤

**技术方案**：
- 后端：新增 API `GET /api/lhb/backtest?signal_type=&months=&group_by=month|sector`
- 在 `lhb_pool` 数据上做聚合统计（已有 d1-d30 涨跌幅字段）
- 前端：在 LhbView 中新增胜率回测 tab，含胜率趋势折线图和板块热力图

**数据基础**：`lhb_pool` 表已有 `d1_change` ~ `d30_change`、`signal_type`、`concept_tags` 字段，数据完整度取决于跟踪天数

---

## P1 - 中频增值

### 5. 自选股关注列表

**目标**：不用每天手动对比自己的持仓

**功能点**：
- 手动添加/删除关注的股票代码
- 当关注股出现在热榜或龙虎榜时高亮提醒
- 关注股的最近上榜记录一览

**技术方案**：
- 新增数据表 `watchlist`（id, stock_code, stock_name, created_at）
- 新增 CRUD API：`/api/watchlist`
- 前端：StockCard 中 watchlist 标识 + 高亮样式；新增 WatchlistView 管理页

---

### 6. 板块热度地图

**目标**：一眼看出今天什么板块最热

**功能点**：
- 聚合 `sector_tags` / `concept_tags`，做板块维度热度排行
- 可视化：treemap 或气泡图

**技术方案**：
- 后端：新增 API `GET /api/stats/sector-heatmap?date=` — 聚合板块出现次数和平均热度
- 前端：ECharts treemap 图表组件

---

### 7. 热榜情绪指数

**目标**：辅助判断市场是过热还是冷清

**功能点**：
- 基于热度值和持仓变化，计算"市场情绪指数"（类似恐贪指数）
- 历史情绪曲线 + 当前位置标注

**技术方案**：
- 需要先定义情绪指数公式（如：加权平均热度变化率 + 持仓变化率 + 新进/退出比例）
- 后端：新增 API `GET /api/stats/sentiment?days=90`
- 前端：情绪指数折线图 + 阈值区间着色

---

### 8. 周报/月报自动推送

**目标**：周总结不用自己翻数据

**功能点**：
- 带分析的报告："本周最热板块 XXX，连板王 XXX，龙虎榜外资净买入 TOP3"
- 页面展示 + 生成信息图
- **推送功能后续再加**

**依赖**：需求1（连板统计）、需求3（日报复盘）的基础设施

---

## P2 - 锦上添花

### 9. 历史数据对比（同日历年对比）

- "去年今天热榜是什么？" — 跨年同期板块轮动对比

### 10. 用户笔记/操作记录

- 每天的热榜记录旁添加笔记，后续和实际涨跌对照复盘
- 需新增 `notes` 表

### 11. PWA / 移动端适配优化

- 当前前端已有响应式，增强为 PWA（离线缓存、桌面图标）

### 12. 数据导出

- 支持导出 CSV/Excel，自选日期范围和字段

---

## 实现建议顺序

```
阶段1：数据基础增强
  需求1（连板统计）→ 需求4（胜率回测）

阶段2：信息深度
  需求2（个股详情）→ 需求3（每日复盘）

阶段3：增值功能
  需求5（自选股）→ 需求6（板块热度）→ 需求7（情绪指数）

阶段4：锦上添花
  需求8~12 按需排期
```

**原因**：需求1（连板统计）是需求3（复盘报告）的前置依赖，需求4（胜率回测）已有最完整的数据基础可立即实现。需求2（个股详情）是独立功能，不阻塞其他需求。
